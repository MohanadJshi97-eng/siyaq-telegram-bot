# SIYAQ | سياق — Cloudflare Edition

بوت تلغرام عام لتفريغ الفيديو والصوت بلغته الأصلية، ثم ترجمته باحتراف مع
التايم كود. يعمل على Cloudflare Workers AI باستخدام Whisper Large V3 Turbo
وQwen، مع Queue للمعالجة وDurable Object للإعدادات والحصص.

## النشر

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/MohanadJshi97-eng/siyaq-telegram-cloud)

اضغط الزر أعلاه وسيتولى Cloudflare نسخ المشروع، وإنشاء Worker وQueue وDurable
Object وربط Workers AI. لا تحتاج إلى تنزيل Node أو Python أو Ollama على جهازك.
أثناء النشر سيطلب Cloudflare توكن BotFather الحالي ويحفظه كسر مشفر؛ لا تضع
التوكن في ملف أو Issue أو رسالة عامة.

بعد نجاح النشر، افتح رابط Worker واضغط **تفعيل وربط البوت**، ثم أرسل `/start`
إلى البوت.

## الحدود الافتراضية

- 18 MB و15 دقيقة للملف.
- 20 دقيقة يوميًا لكل مستخدم.
- 3 ساعات يوميًا لجميع المستخدمين.
- ملفات TXT وSRT وVTT، إضافة إلى النص داخل تلغرام.

## صلاحيات المدير

تُحدَّد حسابات المدير عبر `ADMIN_USER_IDS`. يظهر لها أمر `/admin` فقط، وتُعفى
من حصة المستخدم اليومية مع بقاء الحدود التقنية للملف والمدة وحصة Cloudflare
نفسها. توفر لوحة الإدارة إحصاءات الاستخدام، وقائمة أحدث المستخدمين، وتفاصيل
آخر مهمة، وإلغاء مهام المستخدمين، والحظر وفك الحظر. يستخدم المدير مسار إرسال
فوري، بينما تؤخر مهام المستخدمين ثانيتين لإتاحة الأولوية الإدارية.

إعدادات المشروع مضبوطة لتناسب الحصص المجانية، لكن توفر الخطة وحدودها يخضعان
لسياسة Cloudflare الحالية. يتوقف SIYAQ عند بلوغ حد الاستخدام الداخلي ولا يفعّل
ترقية مدفوعة تلقائيًا. يجب تدقيق الأسماء والأرقام والمواد الحساسة قبل النشر.

## الخصوصية

- لا يُكتب توكن Telegram داخل المستودع.
- تُعالج الملفات مؤقتًا في الذاكرة ولا تُنشأ منها مكتبة دائمة.
- تُحفظ التفضيلات والحصص وحالة المهمة فقط داخل Durable Object.
